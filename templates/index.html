Project Architecture & Model Details

1. System Overview

This project implements Automatic Text Summarization for NLP coursework using sequence-to-sequence neural network architectures. It supports abstractive summarization via Hugging Face Transformers and an extractive baseline for benchmark comparison.

Abstractive Model

DistilBART Transformer

  • Architecture: Encoder-Decoder Sequence-to-Sequence
  • Pretrained Base: sshleifer/distilbart-cnn-12-6
  • Parameters: ~306 Million
  • Mechanism: Multi-Head Self-Attention, Autoregressive Decoding
  • Behavior: Paraphrases and synthesizes new sentences.
Extractive Baseline

TF-IDF Sentence Ranker

  • Algorithm: Term Frequency-Inverse Document Frequency
  • Mechanism: Sentence scoring based on normalized word frequencies
  • Speed: Instantaneous CPU execution (< 0.05s)
  • Behavior: Extracts exact original sentences without rephrasing.

2. Pipeline Workflow

1
Input Parsing & Extraction

Extracts text from TXT, PDF (via pypdf), or DOCX (via python-docx), followed by whitespace normalization.

2
Tokenization & Chunking

Splits long text into max 450-word chunks matching Transformer positional encoding limits.

3
Transformer Generation

Encoder extracts contextual representations; Decoder autoregressively generates summary tokens.

4
Evaluation & Metrics

Calculates compression percentage, inference speed, and estimated ROUGE-1/2/L overlap scores.
